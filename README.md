# fluxor-midia

Mídias públicas da **Fluxor** — imagens de post, carrossel e capa de reel.

O Instagram consome estas imagens por URL `raw`, então **este repositório precisa
continuar público**. Tudo aqui é material já aprovado para publicação.

## Convenção de caminho

```
posts/<slug>/<arquivo>.jpg      imagem de post ou slide
posts/<slug>/<slug>_COVER.jpg   capa de reel
```

URL de consumo: `https://raw.githubusercontent.com/andrelvs87-boop/fluxor-midia/main/posts/...`

## Relação com o repositório antigo

O `fluxia-midia` **não é renomeado nem apagado**. Ele fica congelado servindo as
URLs dos posts já publicados, porque a fila de agendamento e o histórico apontam
para elas. Conteúdo novo vai só aqui.

## Marca e endereço

```
marca      Fluxor
endereço   fluuxor.com.br  ·  @fluuxor
```

A marca escreve-se sempre "Fluxor". A grafia dobrada ("fluuxor") existe apenas
como endereço — domínio, handle e e-mail. As duas grafias nunca aparecem na
mesma peça.
